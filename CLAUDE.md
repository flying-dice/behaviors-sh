## Skills

- **Writing code**: always use @.claude/skills/clean-code/
- **Reviewing changes**: always use @.claude/skills/code-review/
- **UI changes**: always use @.claude/skills/frontend-design/
- **Outstanding items**: always use @.claude/skills/todo-tracker/

Playwright is used for UI testing, but only when asked to do so, otherwise ask the user to use the browser and give feedback.

When using playwright, put screenshots in the `.playwright/` folder and reference them in the report.
