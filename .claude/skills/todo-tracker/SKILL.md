We maintain a backlog of tasks to be completed.
This is a simple Markdown List with the checkboxes.

When asked to add an item do a little bit of research and add it to the list. Dont go to town on implementation detail just try and add enough context to the task to make it actionable without further questions. i.e. get the questions out of the way while adding.

When picking up a task mark it as WIP by changing `- [ ]` to `- [~]`.

When done change `- [~]` to `- [x]` to mark it as done.

When asked to show the list, show the whole list with the status of each item.

For UI/UX items dont mark things as completed unless there is confirmation from the user or with playwright.
